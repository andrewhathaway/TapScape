TapScape

A free daily geography game for the Old School RuneScape (OSRS) world map. You get five locations, you click where you think each one is, and you score by how close you land. Same five for everyone, new set at midnight UTC.

  • Daily — one go a day, with a streak and a 30-day grid.
  • Endless — fresh places whenever you like, and challenge links to send a friend the same five.
  • Clans — a code to share so friends see each other's scores.
  • Hard mode — thirty seconds a round, no zooming in.

Wondering where somewhere is? Every location has its own page with a map and what's nearby. The map and location data come from the OSRS Wiki. Unofficial fan project, not affiliated with Jagex. Open source.
